# 모바일 둘러보기와 장손이 잡기 동작

## 사용자 결정

- 모바일 둘러보기: 말풍선은 왼쪽, 왼쪽을 바라보는 수달은 오른쪽에 놓는다. 섹션 안에서는 수달 영역을 고정하고 카드가 아래에서 스크롤되며, 수달은 걷고 멘트는 카드에 따라 바뀐다.
- 작은 수달: 짧은 터치는 도움말, 길게 누르기는 잡기다. 마우스로 잡거나 길게 누른 동안 버둥거리고, 놓으면 거리별 기존 복귀 동작을 사용한다.
- 사용자가 데스크톱의 얼굴 옆 꼬리 말풍선을 함께 적용하도록 선택했다.
- 사용자가 생성된 잡기 이미지의 눈을 꼭 감고 내려달라는 듯한 표정으로 바꾸도록 요청했다.

## 구현

- `src/styles/landing.css`: 모바일 카드와 안내 영역을 같은 단일 열에 두고, 안내 영역만 섹션 안에서 상단에 붙인다. 안내 영역은 152px이고 첫 카드가 그 아래에서 시작한다. 고정 배경으로 지나가는 글자가 수달 뒤에 비치지 않게 한다. 데스크톱은 얼굴 옆 말풍선과 수달을 가리키는 꼬리를 적용한다.
- `src/styles/hyundai.css`(해당 브랜치): 고정 안내 영역의 배경을 기존 살구색과 맞춘다.
- `src/ui/journey.js`: 모바일 스크롤에서도 기존 걷기 시트의 실제 프레임을 사용한다. 한 번 시작한 900ms 걸음은 스크롤이 빨라져도 재시작하지 않는다. 카드가 바뀌면 멘트를 갱신하고, 섹션을 벗어나거나 화면 이동·입력·모션 감소 설정으로 중단되면 선 자세로 돌아간다.
- `src/ui/companion.js`: 터치는 420ms, 마우스로 누르고 있을 때는 160ms 후 잡는다. 마우스 이동은 기존 이동 임계값에서 바로 잡기로 전환한다. 길게 누르기 전에 손가락을 움직이면 잡기를 취소해 도움말이 잘못 열리지 않게 한다.
- 잡힌 동안 감은 눈의 두 프레임을 140ms 간격으로 교체하고 작은 흔들림을 준다. 모바일은 머리 위 기준점이 손가락을 따라가며, 캐릭터가 화면 밖으로 사라지지 않게 위치를 제한한다. 놓으면 기존 가까운 거리의 균형 잡기(380ms)와 먼 거리의 어지러움(300ms)으로 돌아온다. 잡기 종료·취소는 채팅을 열지 않는다.
- `scripts/mascot-assets.mjs`, 두 팩의 `mascot.json`: 잡기 시트를 기존 이미지 묶음 설정으로 연결한다. 가이드의 작은 수달은 반전 설정을 그대로 사용하며 큰 시작화면의 방향은 바꾸지 않는다.

## 자산

`assets/mascot/packs/guide/grab.png`, `assets/mascot/packs/original/grab.png`는 각각 1774×887의 투명 PNG이며, 887×887 두 프레임을 담는다. 내장 이미지 생성 도구로 만들고 표정을 편집했다. 원본 생성 프롬프트와 최종 표정 편집 프롬프트는 [별도 기록](2026-11-06-mascot-image-prompts.md)에 보존했다.

## 검증

`npm run test:mobile-mascot`은 390×844와 360×640에서 다음을 검사한다.

- 카드 너비, 고정 영역의 화면 안 배치, 말풍선/수달의 좌우 순서, 7개 카드 각각의 멘트와 활성 상태
- 실제 걷기 프레임의 변경과 정지, 섹션을 벗어난 뒤 작은 수달 표시
- 실제 브라우저 터치 이벤트로 짧은 탭, 길게 누르기, 잡기 프레임 교체, 손가락 기준점, 가까운/먼 거리의 복귀
- 길게 누르기 전 이동 및 터치 취소, 잡은 뒤 놓을 때 채팅이 열리지 않는 동작

기존 `test:scroll`, `test:companion`, `test:regression`도 실행해 스냅·방문 기록·안내/채팅·업무 입력 및 결과를 대조한다. 별도 브라우저 프로필을 사용하며 실제 휴대전화 실기기 검사는 포함하지 않는다. 업무 분석 코드·내장 데이터와 기존 기본/걷기/감은 눈 이미지는 이번 작업에서 수정하지 않았다.
